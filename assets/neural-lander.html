Follow the computation THRUST → ACCELERATION → VELOCITY → POSITION → LOSS ↵

96 simulation steps, unrolled into Handwired numerical operations. Gravity, thrust, velocity, position and the loss all execute inside the circuit. backpropagateReference differentiates the loss; Adam updates the 32 bounded thrust values shown above.

Every fresh seed starts randomly. The target is a circuit input: drag it and the same graph adapts. The first ground contact determines the outcome. A landing needs ≤ 0.25 m error and ≤ 0.5 m/s speed. Hovering or crashing before reaching the target does not count.

Trajectories are immutable replays of real training steps. Live metrics may be ahead of the replay. Stored weights describe the compiled graph; trainable values are its input cells. This is trajectory optimization, not reinforcement learning.
